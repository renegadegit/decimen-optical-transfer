# Heliograph — built app

Optical file transfer as an installable offline PWA: one screen, one
camera, no network path between the devices — the payload travels as light
(fountain-coded animated QR). Named for the 19th-century mirror-flash
signalling instrument.

This repository holds the BUILT artifact served at
https://renegadegit.github.io/decimen-optical-transfer/ — the source lives
in a private repository. Derived from bashalarmistalt/decimen-optical-transfer
(MIT); LICENSE included.
